HALAMAN: index.html (Beranda), about.html (Tentang), service.html (Layanan),
project.html (Proyek), feature.html (Keunggulan), team.html (Tim),
testimonial.html (Testimoni), contact.html (Kontak, peta Jakarta), 404.html.

OPTIMASI KECEPATAN:
- Semua font, ikon, jQuery, Bootstrap JS, dan CSS dimuat dari folder sendiri
  (tanpa Google Fonts / CDN). Hanya peta Google dan video YouTube yang
  masih dari luar.
- 1 file CSS (css/app.css) dan 1 file JS (js/app.min.js). CSS Bootstrap sudah
  dipangkas ke bagian yang dipakai. Ikon Font Awesome hanya 18 ikon yang dipakai.
- Gambar .webp dengan lazy-load. File _headers membuat browser menyimpan
  file statis lama (aktif di Cloudflare Pages).

PENTING JIKA MENAMBAH KONTEN BARU:
- Kelas Bootstrap / ikon Font Awesome BARU yang belum ada di halaman bisa tidak
  tampil, karena CSS dan ikon sudah dipangkas. Hubungi pembuat website untuk
  membangun ulang CSS-nya.

YANG PERLU DIGANTI UNTUK KLIEN NYATA:
1. Nama perusahaan, alamat, telepon, email, angka, nama tim, testimoni (semua contoh).
2. Nomor WhatsApp di akhir contact.html (6281234567890).
3. Foto di img/ (foto bawaan template hanya demo); pakai .webp rasio sama.
4. Link video YouTube (index.html, about.html, feature.html) dan link media sosial.
5. Alamat peta di iframe pada contact.html.
Upload seluruh isi folder ke hosting. index.html harus di root.
